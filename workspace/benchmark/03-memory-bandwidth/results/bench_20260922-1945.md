- tag: `20260922-1945`

- ZE_AFFINITY_MASK: `(unset)`

## 关键结论速览

- BabelStream Copy 峰值 **900 GB/s** (数组 256.0 MiB)，= 73% of 1229 GB/s 规格值
- 单向带宽：read **696 GB/s** vs write **851 GB/s** (读 0.82× 于写)
- 双卡并发 copy 合计 **1679 GB/s** (GPU0 839 + GPU1 840)
- 主机 **DRAM** copy 带宽 **39.6 GB/s** (1 GiB/数组, 72 线程)
- 主机内存的 L3 陷阱：16~128 MiB/数组时 copy 报到 **675 GB/s**（命中 432 MiB L3），放大到 1 GiB/数组才落到真实 DRAM 的 40 GB/s
- xpu-smi 显存读写计数器**不可用**：空载 0.000+0.000 GB/s，满载 0.000 GB/s（毫无变化）；`xpu-smi dump` 也完全坏的。带宽绝对值只能以 BabelStream/自研探针为准。
- HBM 规格 1229 GB/s（Max 1100，48 GiB HBM2e）。BabelStream 是行业标准口径，自研探针用于补充单向读/写与访问模式。
